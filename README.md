🛍️ Fashino — Premium Full-Stack E-Commerce Platform

Fashino is a production-ready, full-stack e-commerce web application built with modern technologies and real-world architecture.
It delivers a premium shopping experience with secure payments, AI-powered chatbots, and a powerful admin panel.

🚀 Built to match real industry-level e-commerce systems, not just a demo project.

🔥 Live Demo

🌐 Website: https://fashino.vercel.app

📦 Status: Live (Razorpay LIVE Mode Enabled)

🧠 Key Highlights

✅ Full-stack architecture (Frontend + Backend + Database)

✅ Razorpay LIVE payment gateway

✅ Dual AI chatbots (Product + Support)

✅ Admin dashboard for business control

✅ Scalable & production-ready codebase
